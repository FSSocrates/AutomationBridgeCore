# AutomationBridgeCore Acceptable Use Policy

ABC is provided for legitimate developer testing, accessibility tooling, and consented automation workflows.

**Prohibited:**
- Scraping or automation that violates a website’s Terms of Service
- Automated account creation, credential stuffing, or CAPTCHA farming
- Any use that collects personal data without clear user consent
- Distribution of malware or use in fraud

**CAPTCHA / Challenge handling:**
- Interactive verification is always performed by the end user on-device.
- ABC never solves CAPTCHAs automatically or relays challenge data to third parties.

By using this software you agree to these terms and to comply with all applicable laws.
